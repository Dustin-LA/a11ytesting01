# a11ytesting01

A simple, self-contained TODO application built with plain HTML, CSS, and vanilla
JavaScript. No build step and no dependencies.

## Features

- Add a task
- Mark a task complete or incomplete
- Delete a task
- State persists across page reloads via `localStorage`

## How to run

Open `index.html` in any modern web browser. That's it, there is nothing to install
or build.

## Files

- `index.html` – markup and page structure
- `styles.css` – styling
- `app.js` – application logic (add/toggle/delete + localStorage persistence)
